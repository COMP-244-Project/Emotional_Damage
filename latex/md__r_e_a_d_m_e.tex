\hypertarget{md__r_e_a_d_m_e_autotoc_md2}{}\doxysection{\texorpdfstring{Project Overview}{Project Overview}}\label{md__r_e_a_d_m_e_autotoc_md2}
This project was developed for {\bfseries{COMP-\/244}} and investigates how different classical machine learning algorithms perform on an emotion classification task using TF-\/\+IDF text representations.

The system classifies text into one of seven emotion categories\+:


\begin{DoxyItemize}
\item sadness
\item neutral
\item worry
\item happiness
\item fun
\item surprise
\item hate
\end{DoxyItemize}

The project focuses on\+:


\begin{DoxyItemize}
\item text preprocessing,
\item feature engineering with TF-\/\+IDF,
\item comparative evaluation of multiple classifiers,
\item handling class imbalance,
\item analysing performance under limited training data.
\end{DoxyItemize}

\hypertarget{md__r_e_a_d_m_e_autotoc_md24}{}\doxysubsubsection{\texorpdfstring{Why Linear\+SVC?}{Why Linear\+SVC?}}\label{md__r_e_a_d_m_e_autotoc_md24}
The final model uses {\ttfamily Linear\+SVC}, which is a {\bfseries{linear Support Vector Machine}}.

It does {\bfseries{not}} apply the kernel trick.

This design choice is appropriate because TF-\/\+IDF generates\+:


\begin{DoxyItemize}
\item extremely high-\/dimensional
\item sparse feature vectors
\end{DoxyItemize}

In such spaces, text classes are often approximately linearly separable, meaning linear classifiers perform very effectively while remaining computationally efficient.

Compared with kernel SVMs\+:


\begin{DoxyItemize}
\item {\ttfamily Linear\+SVC} scales significantly better,
\item training is faster,
\item memory usage is lower,
\item sparse matrices are handled efficiently.
\end{DoxyItemize}

Balanced class weights were also used to improve performance on underrepresented classes such as {\ttfamily surprise}.

\hypertarget{md__r_e_a_d_m_e_autotoc_md26}{}\doxysection{\texorpdfstring{Machine Learning Discussion}{Machine Learning Discussion}}\label{md__r_e_a_d_m_e_autotoc_md26}
\hypertarget{md__r_e_a_d_m_e_autotoc_md27}{}\doxysubsection{\texorpdfstring{Why Decision Trees Performed Poorly}{Why Decision Trees Performed Poorly}}\label{md__r_e_a_d_m_e_autotoc_md27}
Decision Trees tend to overfit high-\/dimensional sparse TF-\/\+IDF spaces because they attempt to split on thousands of individual features.

This leads to\+:


\begin{DoxyItemize}
\item unstable decision boundaries,
\item memorization of training noise,
\item weak generalization.
\end{DoxyItemize}

\DoxyHorRuler{0}
\hypertarget{md__r_e_a_d_m_e_autotoc_md29}{}\doxysubsection{\texorpdfstring{Why k\+NN Was Limited}{Why k\+NN Was Limited}}\label{md__r_e_a_d_m_e_autotoc_md29}
Although cosine similarity improves k\+NN performance for text data, k\+NN still suffers from the curse of dimensionality.

In sparse TF-\/\+IDF spaces\+:


\begin{DoxyItemize}
\item distances between samples become less informative,
\item neighborhood quality degrades,
\item classification becomes less reliable.
\end{DoxyItemize}

\DoxyHorRuler{0}
\hypertarget{md__r_e_a_d_m_e_autotoc_md31}{}\doxysubsection{\texorpdfstring{Why Naive Bayes Worked Well}{Why Naive Bayes Worked Well}}\label{md__r_e_a_d_m_e_autotoc_md31}
Despite its unrealistic independence assumption, Naive Bayes performs surprisingly well on many NLP tasks because\+:


\begin{DoxyItemize}
\item word frequencies remain highly informative,
\item probabilistic estimation is efficient,
\item sparse text features align well with multinomial modelling.
\end{DoxyItemize}

\hypertarget{md__r_e_a_d_m_e_autotoc_md33}{}\doxysubsection{\texorpdfstring{Why Linear\+SVC Performed Best}{Why Linear\+SVC Performed Best}}\label{md__r_e_a_d_m_e_autotoc_md33}
Linear SVMs are especially effective for text classification because\+:


\begin{DoxyItemize}
\item TF-\/\+IDF spaces are high-\/dimensional,
\item many classes become approximately linearly separable,
\item margin maximization improves generalization,
\item sparse matrices are processed efficiently.
\end{DoxyItemize}

The model achieved the strongest macro F1 scores across all evaluated configurations.

\hypertarget{md__r_e_a_d_m_e_autotoc_md44}{}\doxysection{\texorpdfstring{Final Conclusions}{Final Conclusions}}\label{md__r_e_a_d_m_e_autotoc_md44}
The experiments demonstrate that\+:


\begin{DoxyItemize}
\item TF-\/\+IDF remains highly effective for classical NLP pipelines,
\item Linear\+SVC is extremely strong for sparse text classification,
\item macro F1 is essential for imbalanced emotion datasets,
\item simpler linear models can outperform more complex alternatives,
\item ensemble methods did not provide sufficient improvement to justify added complexity.
\end{DoxyItemize}

The final system achieved the best balance between\+:


\begin{DoxyItemize}
\item accuracy,
\item generalization,
\item computational efficiency.
\end{DoxyItemize}
